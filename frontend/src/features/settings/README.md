# settings

x-11 `/settings`. PRD §4.1.

- Endpoints: `GET/PATCH /me`, `PATCH /me/whatsapp`, `/members`, `/land-parcels`, `DELETE /me`
- Family members render in the Health theme and land parcels in the Crop theme (each card sets `data-track`).
- Bank shows last 4 only. WhatsApp updates need a verified number and a separate opt-in. Delete asks for confirmation.
